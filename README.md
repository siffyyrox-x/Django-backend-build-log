# Django Backend Build Log

A project-based learning roadmap for becoming job-ready with Django and Django REST Framework.

Instead of only reading concepts, each phase includes practical implementation work so the same project grows as new backend skills are learned.

## Covers

- Django fundamentals
- Models and ORM
- PostgreSQL
- Django REST Framework
- JWT authentication and permissions
- Testing with pytest
- Docker
- Deployment and CI/CD
- Redis and Celery
- Networking and system design
- Production and team practices
- Interview preparation

## Features

- Structured backend roadmap
- Hands-on implementation sprints
- Persistent progress tracking
- Daily study streak
- Dark and animated background modes
- Responsive single-page design
- GitHub Pages friendly

## Learning approach

Learn the concept → implement it → test it → ship the next improvement.

The roadmap gradually builds a production-shaped Django backend instead of treating each topic as isolated theory.

## Tech

HTML, CSS, JavaScript, Mermaid, localStorage
